The validator function returns only True/False. It does not emit a second
normalized object. In the failed receipt every executed validator returned
AAA=, which is the wire encoding of false. The validator-normalized object is
therefore not exposed in the receipt; the exact observable result is:

The important runtime mismatch is in the type of leader_result. Current GenLayer
equivalence semantics pass a gl.vm.Return wrapper to validator_fn, with the
leader value in leader_result.calldata. The installed direct harness implements
this explicitly as gl_vm.Return(calldata=stored_result), and current GenLayer
documentation specifies the same Result/Return contract. The frozen source
passes that wrapper directly to _authentication_matches:

    validator_result = self._authenticate_one(...)
    return self._authentication_matches(leader_result, validator_result)

_authentication_matches begins with:

    if not isinstance(leader_result, dict) or not isinstance(validator_result, dict):
        return False

Thus the hosted validator returns false before any field comparison. This exactly
matches the receipt: false result, successful execution, no exception, call no. 1.

Root-cause classification
-------------------------
ROOT_CAUSE_CLASSIFICATION: C. LEADER_VALIDATOR_LOGIC_MISMATCH

ROOT_CAUSE:
The frozen validator callback assumes leader_result is the raw authenticated
dict. Current GenVM supplies a gl.vm.Return/Result wrapper, whose raw value is
leader_result.calldata. The dict type guard therefore returns false for every
validator. The failed receipt records exactly that false verdict as AAA= with
no validator exception, and NOTIFY_NONDET_DISAGREEMENT is reported for the
first run_nondet call.

This is not classified as volatile RPC fields: five ordinary reads show all
security-relevant projected fields stable, and current_timestamp is excluded.
It is not an internal-time leak: observed_at is assigned after consensus. It is
not a validator exception: validator GenVM execution completed successfully
with empty stderr and null error fields.

Smallest safe source fix (not implemented)
-------------------------------------------
Keep the narrow projection and the fail-closed boolean validator. Change only
the validator-side leader-value handling to accept the current Result wrapper:

    def validator_fn(leader_result: typing.Any) -> bool:
        if not isinstance(leader_result, gl.vm.Return):
            return False
        validator_result = self._authenticate_one(...)
        return self._authentication_matches(leader_result.calldata, validator_result)

Use the exact current runtime wrapper/type API available to the frozen contract
environment. Do not accept arbitrary objects, do not compare raw HTTP bodies,
and do not move observed_at into the nondeterministic result. Keep all existing
hash, sender, origin, target, calldata, finality, execution, consensus,
canonical digest, and target-policy checks unchanged.

SECURITY_MODEL_WEAKENED_BY_FIX: NO.

The fix restores the intended independent validator comparison; it does not
reduce authentication or add tolerance for differing facts. A validator that
cannot return a valid wrapper or whose normalized facts differ still returns
false and fails closed.

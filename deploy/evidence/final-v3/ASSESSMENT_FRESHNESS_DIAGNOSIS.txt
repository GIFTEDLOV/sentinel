1. FROZEN FRESHNESS LOGIC
--------------------------

_copied_evidence obtains now = self._now(). For each evidence ID:
- wrong phase raises: Evidence phase does not match assessment
- if now < record.observed_at: the record is skipped
- if now - record.observed_at > protocol.max_evidence_age_seconds: the record is skipped
- otherwise the record is copied and its source domain is counted once

Assessment freshness therefore is:
FRESH(record) iff now >= observed_at AND
                  now - observed_at <= max_evidence_age_seconds

Assessment rejects when:
len(fresh_evidence) < minimum_sources OR
len(distinct_fresh_source_domains) < minimum_sources

The exact assessment method also requires incident.state == ASSESSING. After
freshness passes, _judge_evidence independently authenticates the chain/advisory
facts and requires the configured source quorum. The current failure occurs
before _judge_evidence, inside _copied_evidence.

_now() is self._transaction_timestamp(), parsed from gl.message.datetime. The
caller cannot supply observed_at.

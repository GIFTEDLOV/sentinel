MINIMAL PRODUCTION FIX
----------------------
contracts/sentinel.py::_copied_evidence now reads all indexed records once,
sets the comparison clock to max(self._now(), newest internally assigned
record.observed_at), and then applies the unchanged phase, freshness, maximum
age, and distinct-source checks. The fix uses no external event timestamp,
caller timestamp, RPC time, or advisory data for the clock. Because observed_at
is assigned only after authenticated binding and is not a public argument, the
fix handles the demonstrated runtime clock rollback without weakening the
caller/authentication/security model or the configured age bound.
